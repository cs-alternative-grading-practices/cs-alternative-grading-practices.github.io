The Alternative Grading Community of Practice Meeting will be held on **February 17, 2027 9:00 pm - 5:00 pm PST**  as a pre-conference event of the **2027 SIGCSE Technical Symposium in Sacramento, California**.

This year's theme is _Nifty Ideas and Best Practice for Adoption_.


### Tenative Schedule

Rough Agenda for the Event:

| Time         | Description |
| --------------- | ----------- |
| 9:00-9:30 | Introductions and plans for the day |
| 9:30-10:00 | Nifty Ideas, Seemed like a Good Idea Presentations |
| 10:00-10:30 | Small Group Reflections on Presentations |
| 10:30-11:00 | Break |
| 11:00-12:00 | Group work: Creation of adoption practices |
| 12:00-1:30 | Lunch as a group |
| 1:30-2:00 | Regroup after lunch and recap morning/prep for afternoon |
| 2:00-3:00 | Group work: Tools needed for alternative grading practices |
| 3:00-3:30 | Break |
| 3:30-4:00 | Presentation of group work highlights |
| 4:00-4:30 | Deeper dives on upvoted outcomes from throughout the day |
| 4:30-5:00 | Planning for future gatherings/meetings |
